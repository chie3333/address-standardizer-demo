## **1. 입력 문자열 및 전처리 오류**

| 유형 | 테스트 입력 예시 | 예상 위험 |
| --- | --- | --- |
| 공백 없음 | `서울특별시강남구테헤란로152` | 토큰 경계 인식 실패 |
| 단어 내부 공백 | `서울 특별시 강남 구 테헤 란로 152` | 지역·도로명 추출 실패 |
| 불규칙 공백 | `서울특별 시강남구 테헤란 로152` | 잘못된 토큰 분리 |
| 여러 공백 | `서울  강남구   테헤란로 152` | 문자열 비교 실패 |
| 줄바꿈·탭 | `서울특별시\n강남구\t테헤란로 152` | 정규화 누락 |
| 오탈자 | `서울특별시 강남구 테헤란로오 152` | 후보 검색 실패 |
| 지역 약칭 | `서울 강남 테헤란로 152` | 정식 지역명 복원 실패 |
| 영문·한글 혼합 | `Seoul 강남구 테헤란로 152` | 지역명 식별 실패 |
| 괄호·기호 | `서울(강남구) 테헤란로 152` | 토큰 오염 |
| 숫자와 문자 결합 | `테헤란로152번지` | 번호 추출 오류 |
| 유니코드 차이 | 전각 숫자 `１５２` | 문자열·숫자 비교 실패 |
| 비정상 입력 | 공백만 입력, `None`, 숫자만 입력 | 파서 예외 또는 오확정 |

**핵심:** 검색용 공백 제거 문자열을 생성하더라도 원본 문자열과 토큰 위치 정보는 유지해야 해.

## **2. 주소 구성요소 누락·순서 오류**

| 유형 | 예시 | 예상 위험 |
| --- | --- | --- |
| 시도 누락 | `강남구 테헤란로 152` | 상위 지역 미확정 |
| 시군구 누락 | `서울특별시 테헤란로 152` | 검색 범위 축소 실패 |
| 읍면동 누락 | `서울특별시 강남구 테헤란로 152` | 불필요하게 매칭 실패 |
| 도로명 누락 | `서울특별시 강남구 152` | 번호만으로 잘못된 후보 |
| 건물번호 누락 | `서울 강남구 테헤란로` | 도로명만으로 주소 확정 |
| 역순 입력 | `152 테헤란로 강남구 서울` | 순서 의존 파싱 실패 |
| 정보 중복 | `서울 서울특별시 강남구 테헤란로 152` | 충돌 또는 중복 추출 |
| 지역·도로명 혼재 | `강남구 서울 테헤란로 152` | 계층 인식 실패 |
| 상충하는 지역 | `서울특별시 수원시 테헤란로 152` | 잘못된 지역 우선 |
| 주소 두 개 결합 | `서울 강남구 ... / 경기 성남시 ...` | 서로 다른 주소 혼합 |

특히 **정보가 없는 것과 정보가 서로 충돌하는 것은 다른 오류**로 처리해야 해.

## **3. 도로명주소 오류**

| 유형 | 예시 | 예상 위험 |
| --- | --- | --- |
| 도로명 내부 공백 | `테헤 란로` | 도로명 검색 실패 |
| 도로명 접미사 분리 | `테헤란 로` | 도로명 추출 실패 |
| 도로명 일부 누락 | `테헤란 152` | 잘못된 도로 후보 |
| 도로명 오타 | `테헤란르 152` | 후보 누락 |
| 동일 도로명 | 서로 다른 지역의 같은 도로명 | 잘못된 지역 확정 |
| 행정구역 경계 도로 | `워커힐로` | 단일 법정동으로 잘못 제한 |
| 본번 누락 | `테헤란로` | 건물 주소 확정 불가 |
| 부번 누락 | `테헤란로 152` | 본번만으로 유일하다고 오판 |
| 부번 표기 | `테헤란로 152-1` | 부번 파싱 오류 |
| 하이픈 주변 공백 | `테헤란로 152 - 1` | 번호 분리 실패 |
| 숫자 붙여쓰기 | `테헤란로152-1` | 도로명·번호 경계 실패 |
| 건물번호·상세번호 혼동 | `테헤란로 152 101호` | 101을 부번으로 오인 |
| 지하 표기 | `테헤란로 지하 152` | 지하 여부 누락 |
| 도로명 숫자 포함 | `세종대로21길 10` | 21을 건물번호로 오인 |
| 도로명 유사성 | `○○로`, `○○로1길` | 상위 도로로 잘못 매칭 |

여기서 중요한 점은 **도로명만으로 법정동을 확정하지 않는 것**이야.

## **4. 지번주소 오류**

| 유형 | 예시 | 예상 위험 |
| --- | --- | --- |
| 법정동 누락 | `강남구 123-4` | 지번 검색 범위 불명확 |
| 본번 누락 | `역삼동` | 필지 확정 불가 |
| 본번·부번 분리 | `역삼동 123 - 4` | 숫자 파싱 실패 |
| 번지 접미사 | `역삼동 123번지` | 숫자 추출 실패 |
| 산 지번 | `○○동 산 12-3` | 일반 지번과 혼동 |
| 산 붙여쓰기 | `○○동 산12-3` | 대지구분 인식 실패 |
| 산 공백 변형 | `○○동 산 12 - 3` | 번호·대지구분 분리 |
| 법정리 누락 | `○○군 ○○면 123-4` | 다른 리의 동일 지번과 충돌 |
| 동일 지번 | 서로 다른 법정동의 `123-4` | 잘못된 필지 선택 |
| 동명 중복 | 서로 다른 시군구의 `중앙동` | 잘못된 지역 선택 |
| 행정동·법정동 혼동 | 행정동명 + 지번 | 법정동 기준 DB 검색 실패 |
| 지번·도로명 혼합 | `역삼동 123 테헤란로 152` | 번호를 잘못된 체계에 연결 |
| 본번 0·부번 0 | `○○동 0-0` | 결측·유효값 처리 혼동 |

특히 `산` 여부는 지번 검색에서 중요해. 원본의 `대지구분코드`와 연결해서 검증할 필요가 있어.

## **5. LLM 토큰 추출·라벨링 오류**

이 부분은 현재 구조에서 특히 신경 써야 해.

| 유형 | 예상 오류 |
| --- | --- |
| 토큰 누락 | 원문에 존재하는 도로명을 추출하지 않음 |
| 토큰 변형 | 원문에 없는 정식 명칭으로 임의 보정 |
| 잘못된 라벨 | 도로명을 읍면동으로 분류 |
| 복합 토큰 | `강남구테헤란로`를 하나의 토큰으로 반환 |
| 과도한 분리 | `테헤란로`를 `테헤란`, `로`로 분리 |
| 중복 추출 | 같은 지역명을 여러 번 반환 |
| 순서 변경 | 원문 순서와 다른 토큰 배열 |
| 라벨 후보 누락 | 모호한 토큰에 단일 라벨만 부여 |
| 숫자 오인 | 도로명 안의 숫자를 건물번호로 분류 |
| 상세주소 혼동 | `101동`을 법정동으로 분류 |
| 존재하지 않는 주소 생성 | LLM이 그럴듯한 도로명 생성 |
| JSON 구조 오류 | 필수 키 누락, 잘못된 배열 구조 |
| ID 불일치 | 입력 주소와 다른 레코드의 토큰 연결 |
| 비결정적 출력 | 같은 주소에 서로 다른 토큰 반환 |

**LLM이 반환한 라벨은 검증 대상이지 확정된 사실이 아니라는 원칙**을 유지하면 좋겠어.

## **6. DB 검색·계층 검증 오류**

| 유형 | 예상 오류 |
| --- | --- |
| 상위 노드 누락 | 시도 추출 실패로 하위 후보 전체 제거 |
| 부모–자식 관계 오류 | 실제로 연결되지 않은 지역 조합 허용 |
| 동일 이름 노드 | 다른 지역의 동명이인 주소 혼합 |
| 도로명–법정동 다대다 | 도로명을 단일 법정동에만 연결 |
| 잘못된 코드 prefix 가정 | 도로명코드와 법정동코드 앞자리 단순 비교 |
| 문자열·정수 혼용 | 코드 앞자리 0 소실 |
| NULL 처리 | 결측값과 실제 0 혼동 |
| 중복 DB 행 | 동일 주소 후보가 여러 개 반환 |
| 부번 비교 오류 | `152`와 `152-0`의 동등성 처리 불일치 |
| 기준연도 불일치 | 2025년 DB에 없는 과거 주소 |
| 정규화 불일치 | LLM 토큰과 DB 명칭의 정규화 방식 차이 |
| 후보 제한 | 검색 상위 N개에서 정답 후보 탈락 |
| 조기 확정 | 일부 계층만 맞는데 전체 주소 확정 |
| 조기 탈락 | 하나의 라벨이 틀렸다는 이유로 전체 후보 제거 |
| JOIN 오류 | 도로명·법정동·번호가 서로 다른 행에서 결합 |
| 캐시 오류 | 과거 검색 결과가 현재 검증 결과에 재사용 |

특히 **각 필드가 개별적으로 존재하는 것과, 그 필드들의 조합이 실제로 존재하는 것은 다르다**는 점이 중요해.

## **7. 결과 판정 및 프론트엔드 오류**

| 유형 | 예상 오류 |
| --- | --- |
| 후보가 여러 개인데 확정 | 모호한 주소의 오확정 |
| 후보 0건 | 정보 부족과 DB 미수록을 동일하게 처리 |
| 후보 점수 동률 | 근거 없이 첫 번째 후보 선택 |
| 후보 근거 누락 | 사용자가 왜 추천됐는지 확인 불가 |
| 코드 일부 불일치 | 3개 코드가 서로 다른 기준 행에서 조합 |
| 주소 체계 오분류 | 지번을 도로명주소로 표시 |
| 성공률 계산 오류 | 후보 제시를 확정 성공으로 집계 |
| 중복 후보 표시 | 같은 주소가 여러 번 나타남 |
| 원본 주소 덮어쓰기 | 사용자가 입력한 문자열 유실 |
| 처리 실패 누락 | 오류가 발생했는데 단순히 결과 없음으로 표시 |
